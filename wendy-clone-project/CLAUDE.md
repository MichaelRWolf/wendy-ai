## Directory Purpose

This subdirectory documents the **Wendy Clone / BLOOM_AI_Core project**—a custom-built AI knowledge system designed to capture Wendy R Wolf's frameworks, content, and voice for reuse, automation, and scaled delivery. The project was born from evaluating Tony Robbins and Dean Graziosi's "AI Advantage Bootcamp" and deciding to build a tailored alternative.

## Key Project Goals

- Build a personalized Wendy Clone system rooted in her frameworks (SoulTECH, Teleios, Egkrateia, consciousness registers)
- Centralize source material (transcripts, programs, session packages) via BLOOM_AI_Core
- Design a sustainable 30-day rhythm that accelerates impact without burnout
- Create metadata tagging using three consciousness registers (Sky-God, God-Personality, Ground-of-Being) to sustain inclusive messaging
- Support revenue-driven offerings: THRIVE enrollment, private clients, lead generation
- Archive and reuse multimedia (podcasts like Mystic rEvolution with co-host Susana Dumett)

## Content Structure

- `notes-wendy.md` — Full 8000+ line ChatGPT conversation transcript where Wendy and ChatGPT co-design the system, covering planning, workflows, transcript ingestion, and folder architecture
- `notes-wendy_summary.md` — Curated synthesis of the planning conversation organized by topic (goals, decisions, action plan, ingested files)
- `notes-wendy_summary.plan.md` — Structured implementation plan with timeline and next steps
- `notes-wendy_summary_critique.md` — Critical review of the plan and its feasibility
- `notes-wendy_transitions.md` — Connective analysis linking themes across the planning

## Michael's Framing

The project prioritizes **revenue validation first, infrastructure second**:

- Focus on real paid experiments (THRIVE pilots, private client calls) before heavy automation
- Use consciousness registers to segment audiences and prove market demand
- Keep tech minimal and text-based until a paid offer validates
- Scale infrastructure only after repeatable revenue is demonstrated
